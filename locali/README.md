# Archivio permanente dei locali\n\nUna scheda JSON per locale, identificata da slug stabile. Non cancellare `locali/<slug>.json` quando termina una serata. `eventi.html` contiene solo gli appuntamenti; `evento.html` unisce data e locale tramite la scheda permanente. Foto in `images/locali/<slug>/`, con percorsi registrati in `gallery[].src` e descrizioni in `gallery[].alt`. Eliminare un evento non deve mai eliminare scheda, logo, contatti o galleria. Per una nuova data si riusa lo stesso slug.\n
